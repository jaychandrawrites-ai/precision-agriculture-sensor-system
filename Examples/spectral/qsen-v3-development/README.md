# QSEN v3 development checkpoint

This trained checkpoint and its diagnostic report are from the historical
AZMET development experiment documented in [AI_VALIDATION.md](../../../AI_VALIDATION.md).
The report includes validation scores, recorded layer statistics, search
generations and the exact checkpoint hash. The checkpoint contains its
feature normalization and historical preparation provenance. The run
used previously examined evaluation dates. This bundle includes selected
plots and excludes raw data and observation/prediction arrays.

Import the directory with the instructions in [QSEN_LOCAL_GUIDE.md](../../../QSEN_LOCAL_GUIDE.md).
New training writes to a separate run directory.
